# Odin Etch A Sketch

Second JavaScript project from **The Odin Project – JavaScript Basics**.  
This project focuses on DOM manipulation by building an interactive sketchpad where you can draw on a grid using your mouse.

## Features

- **Color Picker** – Choose any color to draw with
- **Rainbow Mode** – Draw with random colors on every cell
- **Resizable Grid** – Adjust the grid size from 16×16 up to 32×32 using a slider
- **Clear Button** – Reset the grid and start over

---

## Project Structure

- `index.html` – Structure and controls
- `style.css` – Styling the grid and buttons
- `script.js` – JavaScript logic for the grid and drawing

---

## What I Learned

- How to dynamically create and manipulate DOM elements with JavaScript
- How to use `mouseover` events to simulate drawing
- How to use `flexbox` with `flex-wrap` to build a dynamic grid
- How to toggle between modes (color vs. rainbow) using boolean flags
- How to use `input` event on a range slider to update the UI in real time
- How to generate random hex colors using `Math.random()`
